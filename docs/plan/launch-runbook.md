## 3. 17–19 พ.ย. — ทดสอบเงินจริงยอดเล็ก (#30)
ทำครบวงจร 1 รอบด้วยบัญชีทีมงาน (ลูกค้า 1 + Part-Time 1) ยอดต่ำสุด:
1. ลูกค้าเติม ฿100 ผ่าน QR → สลิปเข้า (Slip2Go หรือแอดมินอนุมัติ) → เห็นยอดใน `/wallet`
2. จองเพื่อน → Part-Time รับงาน → เช็กอิน → (หลังเวลานัด) จบงาน → ลูกค้ายืนยัน + ทิป
3. `/admin/wallet` ตั้ง "ปล่อยเงินหลังจบงาน" = 0 ชั่วคราว → Part-Time เห็น "ถอนได้"
4. ถอนขั้นต่ำ → `/admin/payouts` รวมรอบ → โอนจริงผ่านธนาคาร → กด "โอนแล้ว" → ใบเสร็จออก
5. ทดสอบยกเลิก/ข้อพิพาท 1 นัด → ตัดสินคืน 50% → ตรวจยอดลูกค้า/PT
6. **ตรวจ**: `/admin` "กระทบยอดตรงทุกบัญชี ✓" · ตั้ง "ปล่อยเงิน" กลับเป็นค่าจริง
7. ข้อมูลทดสอบเงินจริงไม่ต้องลบ (ledger แก้/ลบไม่ได้โดยออกแบบ) — ถ้าต้องคืนเงินทีมงานใช้ "ปรับยอดพร้อมเหตุผล"
