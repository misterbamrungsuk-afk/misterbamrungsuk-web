# แผน · โทรผ่านแอป (WebRTC)

ลูกค้ากับเพื่อนโทรเสียงหากันในแอป โดยไม่เห็นเบอร์โทรของกัน เปิดให้โทรได้เฉพาะนัดที่จ่ายเงินแล้ว · สถานะ: **ยังไม่เริ่มพัฒนา** (17 ต.ค. 2569)

## ภาพรวม
- **ไม่ต้องตั้งเซิร์ฟเวอร์ใหม่**: ใช้ Vercel + Supabase ที่มีอยู่ส่งสัญญาณต่อสาย
- **เสียงไม่ผ่านเซิร์ฟเวอร์เรา**: วิ่งตรงระหว่างสองเครื่อง หรืออ้อมผ่านตัวกลาง (TURN) เมื่อเครือข่ายต่อตรงกันไม่ได้ · ไม่อัดเสียง
- **บริการที่ต้องเพิ่ม 1 ตัว**: ตัวกลางส่งเสียง Cloudflare Realtime TURN (บัญชี Cloudflare เดิมของบริษัท)

## การโทรหนึ่งครั้ง
1. **กดโทร**: เช็กสิทธิ์ที่เซิร์ฟเวอร์ (คู่นัดกันจริง · จ่ายแล้ว · อยู่ในช่วงเวลาที่โทรได้) แล้วเปิดสายใหม่
2. **ขอรหัสตัวกลางชั่วคราว**: เซิร์ฟเวอร์ขอจาก Cloudflare ให้เฉพาะสองคนในสาย หมดอายุภายในไม่กี่นาที
3. **แจ้งสายเข้า**: web push + หน้าจอรับสายถ้าเปิดแอปอยู่
4. **แลกข้อมูลเชื่อมต่อ**: ฝั่งละครั้ง (รวบรวม ICE ให้ครบก่อนส่ง ไม่ส่งทีละชิ้น)
5. **คุย**: เวลาในสาย · ปิดไมค์ · ลำโพง · วางสาย
6. **วางสาย**: บันทึกเวลาเริ่ม/จบ/ความยาว · ลบข้อมูลเชื่อมต่อทิ้ง

**การส่งสัญญาณ:** ก่อนอัป Supabase Pro ใช้ API ของเรา ถามความคืบหน้าทุก 1 วินาทีระหว่างต่อสาย (แบบเดียวกับแชทตอนนี้) · หลังอัป Pro ใช้ Supabase Realtime ช่องส่วนตัวต่อคู่นัด (ช่องเดียวกับแชทและแผนที่ live) ถ้าใช้ไม่ได้กลับไปถามทุก 1 วินาทีเอง

## กติกา (ค่าตั้งต้นที่เสนอ ปรับได้)
- โทรได้เฉพาะลูกค้ากับ Part-Time ของนัดนั้น · นัด "ตอบรับแล้ว" หรือ "เช็กอินแล้ว"
- ช่วงเวลา: 2 ชม. ก่อนเวลานัด จนนัดจบ (ช่วงเดียวกับการแชร์ตำแหน่ง)
- โทรได้สองทาง · สายละไม่เกิน 10 นาที · เปิดได้ทีละหนึ่งสายต่อนัด
- ไม่รับภายใน 45 วินาที = สายไม่ได้รับ (แจ้งเตือนอีกฝ่าย)
- นัดที่ถูกบล็อก มีข้อพิพาท หรือยกเลิกแล้ว โทรไม่ได้
- แอดมินเห็นประวัติการโทร (ใครโทร เวลา ความยาว ผลสาย) ในหน้ารายละเอียดนัดและแท็บผิดนัด
- ข้อจำกัด: เสียงพูดกรองเบอร์/LINE ไม่ได้เหมือนแชท การจำกัดช่วงเวลาช่วยลดโอกาสนัดนอกแอปได้บางส่วน

## ส่วนที่ต้องสร้าง
| ส่วน | รายละเอียด |
|---|---|
| ตาราง `booking_calls` | หนึ่งแถวต่อสาย: นัด · ผู้โทร · สถานะ (`ringing` / `active` / `ended` / `missed` / `declined`) · เวลาเริ่ม/รับ/จบ · ความยาว · ข้อมูลเชื่อมต่อ (ลบเมื่อจบสาย) |
| `POST /api/calls` | เปิดสาย · เช็กกติกาทั้งหมดที่เซิร์ฟเวอร์ · ส่ง push · จำกัดความถี่ |
| `GET/POST /api/calls/[id]` | ส่ง/รับข้อมูลเชื่อมต่อ · รับ · ปฏิเสธ · วางสาย · สถานะ |
| `GET /api/calls/[id]/ice` | รหัสตัวกลางชั่วคราวจาก Cloudflare เฉพาะคนในสาย · ไม่มีคีย์ = โทรได้เฉพาะเครือข่ายที่ต่อตรงได้ |
| หน้าจอโทร | โทรออก · สายเข้า · ในสาย · ใช้ทั้งลูกค้าและ Part-Time |
| ปุ่มโทร | หน้าออเดอร์ลูกค้า · หน้างาน Part-Time · หน้าแชทของนัด · บอกเหตุผลเมื่อโทรไม่ได้ |
| หลังบ้าน | ประวัติการโทรในรายละเอียดนัด/แท็บผิดนัด |
| ค่าความปลอดภัยของเว็บ | อนุญาตไมค์เฉพาะหน้าเรา · เพิ่มที่อยู่ตัวกลางในรายการเชื่อมต่อ |
| ชุดทดสอบ | สิทธิ์โทร · วงจรสาย · สายไม่ได้รับ · กันโทรรัว · บันทึกความยาว · โทรจริงระหว่างสองเบราว์เซอร์ |

## ขั้นตอน
1. **ระบบโทรพื้นฐาน**: ตาราง · API · หน้าจอ · ปุ่ม · กติกา · ชุดทดสอบ (ไม่ต้องรอคีย์ ทดสอบในเครือข่ายเดียวกันได้)
2. **ต่อตัวกลาง Cloudflare**: ใส่คีย์ → ทดสอบข้ามเครือข่าย (4G/5G ↔ Wi-Fi · ข้ามค่าย) ทั้ง iPhone/Android · เบราว์เซอร์/แอปที่ติดตั้ง
3. **สายเข้าและหลังบ้าน**: แจ้งเตือนสายเข้าตอนปิดแอป · สายที่ไม่ได้รับ · ประวัติการโทร · เปิดให้ทีมทดลองก่อนเปิดให้ลูกค้า

## ข้อจำกัดของอุปกรณ์
| กรณี | ผล |
|---|---|
| Chrome / Safari บนมือถือ | ใช้ได้ (ขออนุญาตไมค์ครั้งแรก) |
| เว็บที่ติดตั้งไว้หน้าโฮม | ใช้ได้ · แจ้งเตือนสายเข้าดีที่สุด |
| เปิดจากในแอป LINE | ไมค์อาจใช้ไม่ได้ → ปุ่ม "เปิดใน Chrome/Safari เพื่อโทร" |
| สายเข้าตอนปิดแอป | แจ้งเตือนครั้งเดียว ไม่ดังค้างแบบสายโทรศัพท์ · iPhone ต้องติดตั้งเว็บไว้หน้าโฮม |
| ไม่มีตัวกลาง | บางคู่โทรไม่ติด → ต้องทำขั้นที่ 2 ก่อนเปิดให้ลูกค้า |

## ค่าใช้จ่าย
| ส่วน | ค่าใช้จ่าย |
|---|---|
| เสียงโทร | ฟรี (ส่วนใหญ่ต่อตรง) |
| ตัวกลาง Cloudflare | น่าจะอยู่ในโควตาฟรี: 100 สาย/วัน × 3 นาที ≈ 9–18 GB/เดือน แม้ทุกสายผ่านตัวกลาง (เช็กหน้าราคาตอนเปิดใช้) |
| ส่งสัญญาณ · บันทึกการโทร · แจ้งเตือน | รวมใน Vercel Pro / Supabase Pro ที่ต้องอัปอยู่แล้ว |
| ค่าโทรรายนาที / ค่าเบอร์ | ไม่มี |

ไม่ใช้ Droplet: เสียงไม่ผ่านเซิร์ฟเวอร์เรา · ค่อยพิจารณาตั้งตัวกลางเอง (coturn) บน Droplet สิงคโปร์เมื่อปริมาณโทรเกินโควตาฟรี

## สิ่งที่เจ้าของระบบต้องเตรียม
1. เข้าบัญชี Cloudflare เดิมของบริษัท → เปิด Realtime TURN → สร้าง TURN key (ได้ Key ID + API Token)
2. ใส่สองค่าใน env ของ Vercel (ชื่อตัวแปรจะระบุตอนทำขั้นที่ 2)
3. ยืนยันกติกา: ช่วงเวลาโทร · ความยาวสาย · เวลารอรับสาย
